# Inflow and Outflow Simulation

## Overview

This project presents a simple hydrological simulation of inflow and outflow discharge over time. The model demonstrates the relationship between incoming flow (inflow) and released flow (outflow) and visualizes their variation using hydrographs.

The simulation is developed using Python to analyze discharge response and identify peak inflow and outflow conditions.

---

Variables:

- **Inflow (I(t))**: Incoming discharge (m³/s)
- **Outflow (O(t))**: Released discharge (m³/s)
- **Time**: Simulation duration (hours)
